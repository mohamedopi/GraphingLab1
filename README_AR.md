# Graphing Lab — مشروع Android جاهز للبناء على GitHub

## ماذا يحتوي؟
- مشروع Android Studio باستخدام Kotlin وWebView.
- واجهة محلية مضمّنة؛ لا تحتاج الإنترنت عند تشغيل التطبيق.
- رسم 2D للدوال y=f(x).
- رسم 3D للأسطح الديكارتية z=f(x,y)، والأسطوانية z=f(r,theta)، والكروية r=f(theta,phi).
- تدرّج ألوان أزرق/سماوي/أخضر/أصفر، تدوير باللمس، ونطاقات ودقة قابلة للتغيير.
- GitHub Actions يبني APK ويرفعه كـ Artifact.

## إنشاء APK بأبسط طريقة
1. أنشئ مستودعًا جديدًا على GitHub.
2. فك ضغط هذا الملف، ثم ارفع **كل المحتويات** إلى جذر المستودع. تأكد أن `settings.gradle` و`app` و`.github` تظهر في الصفحة الرئيسية.
3. افتح تبويب Actions وفعّل GitHub Actions إذا طُلب ذلك.
4. شغّل Workflow باسم **Build Graphing Lab APK** عبر Run workflow، أو ادفع الملفات إلى الفرع main.
5. بعد نجاح البناء افتح عملية التشغيل، وانزل إلى Artifacts، ونزّل `GraphingLab-debug-apk`.
6. فك ضغط الملف الناتج وثبّت `app-debug.apk` على هاتف Android.

## مهم
هذا مشروع قابل للبناء ويحتوي على ميزات الرسم المذكورة، لكنه ليس محركًا رمزيًا عامًا لكل المعادلات. المعادلات الضمنية مثل F(r,theta,phi)=0 لا تُحل تلقائيًا في هذه النسخة. الزوايا بالراديان. استخدم ^ للأسس والدوال sin, cos, tan, sqrt, abs, exp, log, asin, acos, atan, min, max.
